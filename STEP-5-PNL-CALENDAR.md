# Step 5 — P&L Calendar

Adds a dark performance calendar inspired by the provided reference image while keeping Trading Journal Pro's own branding and data model.

## Included
- Daily P&L calendar with green profitable days and red losing days
- $ P&L / R Multiple toggle
- Click a day to inspect all closed trades for that date
- Monthly trading-day summary
- Closed trades tab
- Charts tab with cumulative P&L, daily P&L and cumulative R
- All-time metric cards: equity, win rate, net/gross P&L, profit factor, best/worst trade, expectancy and average trade size
- User-settable starting equity stored locally in the browser

No Supabase migration is required. All data is calculated from the existing `trades` table.
