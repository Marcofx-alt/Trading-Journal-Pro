# Step 8 — Unified navigation and home polish

Version 23.2 reorganizes the app without removing any active feature.

## Changes
- Desktop navigation is grouped around the actual trading workflow.
- Compact icon sidebar keeps its hover labels while adding subtle group separators.
- Mobile navigation is grouped into Plan & Trade, Review & Improve, and Research & System.
- P&L Calendar is promoted to the main mobile bottom bar.
- Home now includes a Core Workspace section for the most-used tools.
- Home workflow is simplified to Plan → Protect → Record → Review.
- Sidebar/footer version updated to 23.2.

No Supabase migration is required.
