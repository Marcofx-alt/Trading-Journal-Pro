# Trading Journal Pro for Windows

**Built by Marco.N**

This folder now includes a Tauri 2 Windows desktop shell for Trading Journal Pro.

## Quick start

1. Edit `src-tauri/app-url.txt` and enter your live Vercel URL.
2. Run `npm install`.
3. Run `npm run desktop:check`.
4. Run `npm run desktop:dev`.
5. When ready, run `npm run desktop:build` to create the installer.

See `docs-windows.md` for the complete setup guide.
